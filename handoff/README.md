# GPT ↔ Codex Handoff

This directory is the stable handoff boundary for Kitao Body Collage Lab.

Start with `latest_status.md`. Completed stage reports live in `reports/`. After each meaningful development stage, Codex must run the relevant tests, update the formal report and `latest_status.md`, then commit and push the milestone to `main`.

Temporary experiments, model weights, source photographs, generated validation images, caches, and local credentials must never be added here or committed to the repository.
